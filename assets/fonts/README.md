# Font Assets

This directory should contain the Inter font family files:

- Inter-Regular.ttf
- Inter-Medium.ttf  
- Inter-SemiBold.ttf
- Inter-Bold.ttf

You can download these fonts from:
- Google Fonts: https://fonts.google.com/specimen/Inter
- Inter Font Website: https://rsms.me/inter/

## Installation

1. Download the Inter font family
2. Copy the required .ttf files to this directory
3. Ensure the filenames match exactly what's referenced in App.tsx

## Required Files

```
assets/
  fonts/
    Inter-Regular.ttf
    Inter-Medium.ttf
    Inter-SemiBold.ttf
    Inter-Bold.ttf
```

The app will fall back to system fonts if these files are missing, but for the best design experience, please install the proper font files.
